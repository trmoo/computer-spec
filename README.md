# 💻 나에게 쏙 맞는 노트북 고르기

고등학교 「정보」 Ⅰ. 컴퓨팅 시스템 — **문제 해결에 적합한 하드웨어를 선택하기** 수업용 웹앱입니다.
노트북 사양표(CPU·화면·포트·램·저장장치)를 읽는 법을 익히고, 나의 사용 목적에 맞는 노트북을
골라 그 까닭을 설명합니다. 활동한 내용은 **HTML 활동지 파일로 내려받아** 제출할 수 있습니다.

- 바로 쓰기: https://trmoo.github.io/computer-spec/
- 인터넷 없이 쓰기: `dist/index.html` 한 파일을 더블클릭

## 화면 구성 (탭 7 · 화면 22 · 확인 문제 74)

| 탭 | 하는 일 |
|---|---|
| ① 선택 기준 | 기준 9가지 카드 · 「이 걱정은 어떤 기준?」 9문항 · **나의 기준 순위 정하기** |
| ② 노트북 종류 | 2in1·초경량·장시간 배터리·게이밍 · 문장 카드 12장 나누기 · 상황 5문항 |
| ③ 화면·포트 | 실제 비율 화면 크기 비교 · 인치 계산기 · **해상도 실험실**(픽셀을 그대로 확대) · 주사율 · 단자 그림 · 전송 시간 계산기 |
| ④ CPU | 회사와 구조(x86·ARM) · **모델명 해부기** · 코어·스레드 조립기 · 접미사 · 클럭·터보·NPU |
| ⑤ 그 밖의 부품 | 그래픽카드 · 램·저장장치 · 무게·제조사 · 확인 문제 |
| ⑥ 종합 미션 | 인물 4명에게 맞는 노트북 · **나에게 쏙 맞는 노트북 고르기**(내 기준 점수·조건 점검·까닭 쓰기) |
| ⑦ 내 활동지 | 진행 상황 · 배움 정리 · **활동지 내려받기(.html)** · 이어하기 파일 저장/불러오기 · 기록 지우기 |

주소 끝에 `#cpu/decode` 처럼 붙이면 그 화면이 바로 열립니다.

## 수업에서 쓰는 법

1. 학생은 ①부터 차례로 풀고, ⑥에서 노트북을 고른 뒤 ⑦에서 학번·이름을 적어 **활동지 파일을 내려받아 제출**합니다.
2. 다음 시간에 이어서 하려면 ⑦의 **[이어하기 파일 저장]** 으로 `.json` 을 받아 두었다가 **[불러오기]** 합니다.
3. 공용 컴퓨터라면 수업 끝에 **[내 기록 지우기]** 를 누릅니다.

## 개인정보

서버가 없습니다. 활동 기록은 그 브라우저에만 남고, 학번·이름은 **내려받는 활동지 파일에만** 들어갑니다.

## 개발

```bash
npm install
npm start            # 개발 서버
npm test             # 시험 1,168가지
npm run check:syntax # 소스 전수 검사(문법·저작권·조사·개인정보 규칙)
npm run build        # dist/index.html 한 파일
```
